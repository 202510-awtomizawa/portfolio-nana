ToDoアプリ

作品概要 必須
どんなサービス・サイトか、ターゲットユーザーは誰か

Todoアプリを制作。20〜30代の働く方を対象に、タスクを効率的に管理できる設計を意識しました。カテゴリ分類や期限・優先度設定、完了状況の可視化に加え、言語切り替え機能を実装し、使いやすさと実用性を重視して1〜2か月で開発しました。

使用技術 必須

フロントエンド：HTML / CSS / JavaScript

バックエンド：Java / Spring Boot / MyBatis

データベース：MySQL

その他：Git

担当範囲 必須
企画・デザイン・フロントエンド・バックエンドなど

企画・デザイン・フロントエンド・バックエンドの開発

工夫した点・アピールポイント 必須

Todoアプリでは、タスク一覧の見やすさと管理のしやすさに注力しました。優先度や期限を整理して表示することで、直感的に状態が把握できるUIを設計しました。また、カテゴリごとにページを分けることで、情報の整理と操作性の向上を図りました。特に言語切り替え機能の実装に苦労しましたが、課題を細分化し、段階的にプロンプトを作成して検証を重ねることで解決しました。
